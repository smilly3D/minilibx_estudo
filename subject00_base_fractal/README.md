# Subject 00: A Base do Fractal

Este é o ponto de partida. O código em `main.c` renderiza o fractal de Mandelbrot em uma janela, mas não possui interatividade.

## Objetivos

1.  **Compilar e Executar**: Familiarize-se com o `Makefile`. Use `make` para compilar e `./fractal` para executar.
2.  **Analisar o Código**: Entenda a função de cada parte do programa, especialmente `render_fractal`, `mandelbrot_iters`, e o `loop_hook`.
3.  **Consultar o Guia**: Leia o `FRACTAL_GUIDE.md` na raiz do projeto para compreender a matemática por trás do código.

Este exercício é a fundação para os próximos, onde adicionaremos interatividade e melhorias visuais.
